## Descrição do Projeto
O **TaskTracker** é um sistema simples e prático desenvolvido em Python para gestão de tarefas individuais ou de equipas. Ele resolve problemas de desorganização, esquecimento de prazos e falta de priorização, permitindo cadastrar, organizar e acompanhar as atividades diárias via linha de comandos (CLI).
